Платформа мини-приложений: Android-оболочка + статические пакеты + MiniApps API.

Скачать оболочку
mini-apps-shell.apk · релизы shell

Архитектура

  • mobile-shell — Capacitor/Android runtime, Service Worker, пакеты в mapp/apps/
  • app-* — мини-приложения; релиз публикует app.zip
  • Нет +server.js — логика через MiniApps.* (shell API) и MiniApps.net
  • Каталог — catalog.json

MiniApps API (кратко)

await MiniApps.apps.list()
await MiniApps.hub.getHome() / setHome({ appId })
await MiniApps.share.start({ appId }) / stop / list
await MiniApps.net.send(payload, type)
MiniApps.net.on(type, handler)
await MiniApps.db.local.open(name)
await MiniApps.db.local.get/set(name, key, value)
await MiniApps.notify.toast({ text })
await MiniApps.shell.setChrome({ title, topBar, bottomBar })

{

}

  • app-chat — чат
  • app-fileshare — обмен файлами
