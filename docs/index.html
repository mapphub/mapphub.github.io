Как это работает для пользователя

  1. Пользователь находит проект на GitHub Pages и скачивает APK оболочки.
  2. При первом запуске оболочка смотрит настройку домашнего приложения (по умолчанию — launcher / рабочий стол, сейчас пакет market) и скачивает его ZIP из каталога, если ещё не установлен.
  3. После установки оболочка запрашивает разрешения из манифеста. Если пользователь отказал частично или закрыл окно — показывается предупреждение об ограниченном функционале с возможностью вернуться к разрешениям или продолжить.
  4. Открывается рабочий стол (launcher): иконки установленных мини-приложений + иконка каталога (минимаркет).
  5. На хосте (телефон с оболочкой) открывается host-версия пакета. В онлайн / встроенном браузере открывается client-версия с GitHub Pages. Каталог на клиенте показывает список с каталога аккаунта и отмечает уже установленные через MiniApps.apps.list().
  6. Если приложение не установлено — по тапу открывается веб-версия; в шапке встроенного браузера справа — действие «Установить» / «Удалить».
