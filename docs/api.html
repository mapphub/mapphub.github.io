MiniApp API

MiniApp — прокси к оболочке. Канонический вызов:

await MiniApp.<category>(action, { ...params })

// примеры
await MiniApp.apps('list', {})
await MiniApp.apps('checkUpdate', { appId: 'chat' })
await MiniApp.apps('installUpdate', { appId: 'chat' })
await MiniApp.net('send', { text: 'hi' })
await MiniApp.db('local.set', { name: 'kv', key: 'a', value: 1 })
await MiniApp.shell('setChrome', { title: 'App', topBar: true })
await MiniApp.notify('toast', { text: 'OK' })

Алиас MiniApps = MiniApp (совместимость). События: miniapp-ready / miniapps-ready.
