MiniApps API

Вызов из мини-приложения:

// category(action, params)
await MiniApps.apps.list()
await MiniApps.apps.checkUpdate({ appId: 'chat' })
await MiniApps.net.send({ text: 'hi' }, 'message')

// или универсально через bridge
await MiniApps.call?.('apps', 'list', {})

Легенда: ● работает · ◐ ограничено · ○ нет

apps — пакеты

МетодПараметрыHostClientWebОписание

installUpdate{ appId, packageUrl?, catalogUrl? }●○○Скачать ZIP и переустановить пакет.
create{ name }●○○Создать пустой пакет (редактор).
remove{ appId }●○○Удалить пакет с устройства.

Обновление оболочки (не API мини-приложения)

Оболочка сама проверяет update.json при холодном старте и из меню «Проверить обновления». Внизу меню оболочки показывается текущая версия APK.
