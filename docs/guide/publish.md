# Публикация

1. Создайте приложение из [gateway](https://github.com/mapphub/gateway) (Use this template) **или** PR в gateway.
2. Заполните `mappmanifest.json` (`id`, `version`, `author`).
3. Push в `main` → Action собирает `app.zip`, Release, при `web: true` — Pages.
4. Запись появляется/обновляется в `market/catalog.json` на mapphub.github.io.
