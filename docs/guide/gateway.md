# Шаблон для разработчиков

Стартовая точка: **[mapp-template](https://github.com/mapphub/mapp-template)**

1. **Use this template** → репозиторий `app-<id>`
2. Заполните `mappmanifest.json`
3. Push → CI собирает `app.zip` и при необходимости Pages
4. Каталог: [market/catalog.json](https://mapphub.github.io/market/catalog.json)
