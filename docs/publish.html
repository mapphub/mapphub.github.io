Обзор Манифест MiniApps API Публикация

Публикация мини-приложений

Стартовая точка: репозиторий-шаблон mapphub/mapp-template.

Структура шаблона

mapp-template/
├── .github/workflows/gateway.yml   # оркестратор PR
├── package.json                    # version: "1.0.0"
├── src/                            # исходники разработки (опционально)
├── .gitignore
└── mapp/                           # то, что попадает в ZIP
    ├── mapp.manifest.json          # манифест (нормализуется в mappmanifest.json)
    ├── icon.png | icon.svg
    └── public/                     # веб-морда (строго public/)
        ├── index.html
        └── script.js

Карта: разработчик → CI

ШагРазработчикGateway
1Fork mapp-template, ветка = имя приложения (например snake)ожидание
2Код, версия в package.json, сборка статики в mapp/public/ожидание
3Push ветки в свой форкожидание
4PR: fork/snake → mapp-template branch snakepull_request_target
5—Читает AUTHOR, NAME, VERSION; пишет в манифест; создаёт app-AUTHOR-NAME; gh-pages из mapp/public/
6—ZIP из mapp/ → Release latest (и vX.0.0 при мажоре)
7—Обновляет catalog.json в mapphub.github.io
8Ссылки в комментарии PRPR закрывается без merge

Запись catalog.json

{
  "id": "AUTHOR.NAME",
  "name": "NAME",
  "version": "1.0.0",
  "description": "…",
  "author": "AUTHOR",
  "repo": "https://github.com/mapphub/app-AUTHOR-NAME",
  "packageUrl": "https://github.com/mapphub/app-AUTHOR-NAME/releases/latest/download/app.zip",
  "releaseUrl": "https://github.com/mapphub/app-AUTHOR-NAME/releases/latest/download/app.zip",
  "webUrl": "https://mapphub.github.io/…",
  "permissions": [],
  "official": false
}

Обновление точечное по паре name + author, иначе append в массив apps.

Требования к gateway.yml

  • on: pull_request_target (opened, synchronize)
  • Токен: ${{ secrets.ORG_ADMIN_TOKEN }}
  • Автор: github.actor должен совпадать с полем author после записи
  • Правки JSON через jq, сохраняя кастомные поля разработчика
Статус
Workflow gateway внедряется в mapp-template. Пока секрет ORG_ADMIN_TOKEN не задан в org — шаг 5–7 выполняются вручную или после настройки secrets.
