Обзор Манифест MiniApps API Публикация

mappmanifest.json

Файл в корне пакета мини-приложения. Оболочка читает его при установке, открытии и проверке обновлений.

Полный пример

{
  "id": "chat",
  "name": "Чат",
  "version": "1.2.0",
  "description": "LAN-чат",
  "author": "mapphub",
  "icon": "icon.svg",
  "routes": {
    "root": ".",
    "app": ".",
    "client": "."
  },
  "server": {
    "host": true,
    "client": true,
    "network": true,
    "samePort": true,
    "forceHttp": false
  },
  "permissions": ["net", "share", "db", "notify"],
  "tags": ["social"],
  "system": false,
  "launcher": false,
  "webUrl": "https://mapphub.github.io/apps/chat/"
}

Поля

ПолеТипПо умолчаниюОписание
idstring—Уникальный идентификатор пакета. Латиница, цифры, ._-. На устройстве каталог = mapp/apps/{id}/.
namestring= idОтображаемое имя на рабочем столе и в каталоге.
versionnumber | string1Версия пакета. Число или semver (1.2.0). Используется в apps.checkUpdate.
descriptionstring""Краткое описание.
authorstring—Автор (логин GitHub). В каталоге сторонних: часть id author.name.
iconstring—Путь к иконке относительно корня пакета (icon.svg / icon.png). SVG предпочтительно с fill="currentColor".
routes.rootstring"."Корень содержимого пакета (статика).
routes.appstring= rootТочка входа host-UI (папка относительно пакета).
routes.clientstring= appТочка входа client-UI (LAN / веб-превью).
server.hostbooltrueМожет работать как host-приложение на оболочке.
server.clientboolfalseЕсть client-режим (LAN-гости, веб).
server.networkboolfalseРазрешить публикацию по сети (share).
server.samePortbooltrueHTTP и WS на одном порту, если возможно.
server.forceHttpboolfalseВсегда поднимать локальный HTTP, даже без client.
server.portnumber?autoПредпочтительный порт (если свободен).
permissionsstring[][]Запрашиваемые разрешения при первом открытии. См. таблицу ниже.
tagsstring[][]Метки для каталога.
systemboolfalseСистемное (нельзя удалить из launcher без спец. прав).
launcherboolfalseМожет быть домашним приложением оболочки.
webUrlstring?—URL веб-версии (GitHub Pages) для встроенного браузера каталога.

permissions

КодСмысл
*Полный доступ ко всем API
shareЛокальный HTTP/WS для доступа по LAN
netОбмен сообщениями в реальном времени
notifyТосты и бейджи
db / db.localЛокальное key-value / SQLite хранилище
apps / apps.manageУстановка и удаление пакетов
apps.readЧтение файлов других приложений
apps.writeЗапись в пакеты других приложений
device, device.camera, device.geoВозможности устройства
shellУправление chrome оболочки

Имена файлов: в текущей оболочке канонический файл — mappmanifest.json (также допускается mapp.manifest.json в шаблоне после нормализации CI).
